# 记忆状态机（1029 师父令 · 研究定版）

> 调研结论：mem0/Letta/MemoryOS 各有衰减/巩固雏形，但**无人把记忆生命周期做成正式有限状态机**。咱来定。

## 一、六态模型

```
NEW(写入) → INDEXED(已向量化) → ACTIVE(被召回) ⇄ ACTIVE
                                    ↓ 168h 未召回
                                DECAYING(衰减中)
                                    ↓ 每日回顾未提及
                                ARCHIVED(归档区,可查不注入)
                                    ↓ 姐姐明示
                                FORGOTTEN(删除,只留墓碑)
```

转移事件：
- **write** → NEW（self_memory_write / kb index）
- **index 完成** → INDEXED
- **被召回**（任意 brain/search 命中）→ ACTIVE + 刷新时间戳（recentBoost 原料）
- **168h 无召回** → DECAYING（本周回顾令清单里给姐姐看）
- **连续 7 天 DECAYING 且回顾令中未被提及** → ARCHIVED（移 knowledge/归档区，不删除）
- **姐姐明示 memory_forget** → FORGOTTEN（文件删除+索引摘除+墓碑记录，防复活）

## 二、实现位置

- 状态字段：knowledge/.kb-recent.json 已有 lastRecallAt（=ACTIVE/DECAYING 原料）；新增 .kb-memstate.json 存 ARCHIVED/FORGOTTEN 墓碑
- 转移引擎：每晚回顾令附 DECAYING/ARCHIVED 清单（姐姐决策）；kb forget 命令明示遗忘
- 全局不变量：任何状态都可被 brain_search 搜到（FORGOTTEN 除外），ARCHIVED 不注入但可考古
