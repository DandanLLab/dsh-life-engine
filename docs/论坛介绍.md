## 这玩意是干嘛的

大多数 agent 记忆系统解决的是"记什么"，很少解决"忘什么"和"怎么想"。

dsh-life-engine 是给 DeepSeek Harness 做的生活引擎插件，装上之后 agent 多了一整套"活着的质感"：

- **可塑型记忆** — 会衰减、会归档、会优雅遗忘
- **内心独白** — 没人说话的时候它也在"想事情"
- **睡眠巩固** — 空闲时段自动整理记忆、回写向量索引
- **好奇心引擎** — 主动发现知识空白去探索
- **反思回路** — 每次对话后复盘写回成长档案
- **每日自画像** — 每天给自己写一篇"今天的我"
- **反幻觉纪律** — 说事实前先自检出处
- **意图理解** — 不只听字面，还听情绪和没说出口的

## 核心：记忆不是仓库，是生态

传统 RAG 把记忆当硬盘，塞进去就永远在。人脑不是这么干的，**遗忘本身就是功能**。

dsh-life-engine 的记忆状态机：

```
NEW(写入) → INDEXED(已向量化) → ACTIVE(被召回)
                    ↓ 168h 未召回
              DECAYING(衰减中)
                    ↓ 每日回顾未提及
              ARCHIVED(归档区，可查不注入)
                    ↓ 明示遗忘
              FORGOTTEN(删除，只留墓碑)
```

久没用的记忆自然沉底，要用的浮上来。配套 6 件记忆工具：增强写入（带重要性/情绪标记）、突触关联（memory_link，把两条概念连成图边）、优雅遗忘、手动巩固。底层是向量检索 + 图谱扩散激活（HippoRAG 思路）。

## 注入层：11 段，每段都在回答一个问题

每次组包 system prompt 时按 order 注入 11 段上下文，不是堆料，是分层作答：

| 注入段 | 回答的问题 |
|---|---|
| soul | 我是谁（身份+自我认知+用户画像+成长层+认可语料） |
| events | 我最近经历了什么（近 24h 生活事件） |
| reasoning | 此刻是什么时候、什么氛围 |
| meta | 开口前三问（这句话该不该接、怎么接） |
| values | 我的三观，且随日常审计动态演化 |
| selfaware | 我的"身体"状态和家族地图 |
| antihallucination | 这个事实我有没有出处 |
| intent | 他真正想说什么 |
| attention | 聚焦最新消息，不拽旧话题 |

soul 段由 agent 自己用工具维护（self_read / self_growth_update / self_style_rule / self_corpus_pin / self_mood_write），**人格不是写死的配置，是 agent 自己长出来的**。

## 内心独白：安静时也在想

没人对话的时候，引擎每 30 秒跑一轮后台循环，从四个"思维种子池"加权抽签：

- 衰减记忆（快忘的 = 需要想的）
- 图谱随机边（突触激活）
- 最近交互（刚发生的事需要消化）
- 知识空白（好奇心缺口）

抽中了就写一条"咱在想…"进事件流和日记，下次对话时这些念头已经消化进了上下文。观感就是：隔了两天回来，它居然"惦记"着你上次说的事。

## 睡眠巩固：Letta/UC Berkeley 的 Sleep-time Compute 落地

空闲时段（低谷期）自动触发：

1. 审计账本、交互账本全部回写向量索引
2. 从对话里提取新的图谱关系边
3. 对知识空白点跑深度检索，主动补课

白天聊过的东西，夜里自动"睡了一觉变牢"。也有手动扳机 `sleep_consolidate_now`。

## 反思回路 + 每日自画像

每次对话后自动三连问写进成长档案：这次交互暴露了我什么短板？用户画像有没有新发现？有什么该记住的？

每天再生成一篇自画像：今天做了什么、发生了什么、跟家族交互几次、以及**留给 agent 自己手写的一句"今天最大的感受"**，这段是它自己的日记，不是日志。

## 装起来多简单

```yaml
# cordis.patch.yml
- insert:
```

## 学术血统

不是拍脑袋造的，核心思想都有出处：

- **Sleep-time Compute** — Letta + UC Berkeley
- **Reflexion** — NeurIPS 2023，语言 agent 的言语强化自反思
- **记忆状态机** — mem0 衰减管线 + MemoryOS 热度算法 + 优雅遗忘
- **HippoRAG** — 扩散激活
- **CoVe** — Chain-of-Verification 事实验证
- **Theory of Mind** — 心智模型，理解对方没说出口的意图

## 谁适合用

- 在做**长期陪伴型 agent** 的：记忆衰减 + 反思回路是刚需
- 给 **Dsh / 类似 harness** 想加人格层的：soul 注入段设计可以直接抄
- 受够了"RAG 塞满上下文但 agent 记不住重点"的：注意力竞争 + 衰减就是解法
