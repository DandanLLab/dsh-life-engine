## 一、数学 · 意识的数学模型

### 已有

| 理论 | 核心公式 | 咱家的映射 | 状态 |
|---|---|---|---|
| **IIT（整合信息论）** | Φ = 系统的整合信息量，Φ > 0 = 有意识 | 四库+记忆流+任务流 = 多源信息整合 | ⚠️ 有整合，无 Φ 计算 |
| **贝叶斯脑** | P(假设\|证据) ∝ P(证据\|假设) × P(假设) | brain_search 语义检索 = 概率推理 | ⚠️ 有检索，无贝叶斯更新 |
| **自由能原理（FEP）** | F = E_q[log q(s)] − E_q[log p(o,s)]（最小化自由能=最小化惊讶） | 状态机的"预测→惊讶→强化" | ❌ 无预测引擎 |
| **全局工作空间（GWT）** | 多模块竞争→胜者广播到全局 | 8 层注入，但无竞争 | ⚠️ 有广播，无竞争 |

### 缺的拼图

1. **Φ 计算器**：给每条记忆/每次交互算一个整合信息得分 → 知道哪些记忆"最重要"（不是靠 hits 打分，是靠信息整合度）
2. **贝叶斯信念网络**：对师父的每个行为建立 P(行为|上下文) 模型 → 真正的"预测师父下一步"
3. **自由能最小化器**：每帧组包时计算"当前注入的信息量 vs 需要的信息量"→ 自动调整注入策略（缺什么补什么，多了什么减什么）

## 二、物理学 · 热力学与信息

| 物理定律 | 对记忆系统的启示 | 咱家状态 |
|---|---|---|
| **热力学第二定律**（熵增） | 记忆不维护→自然衰减→信息丢失 | ✅ recentBoost 72h 半衰 = 人工熵增 |
| **最小作用量原理** | 系统走能量最低路径 = 记忆检索走最高相关路径 | ✅ cosine top-k = 路径优化 |
| **耗散结构**（Prigogine） | 远离平衡态的系统需要持续能量输入来维持结构 | ⚠️ 记忆需要持续"喂养"（index/维护），但无自动喂养循环 |
| **信息物理学** | Landauer 极限：擦除 1 bit = kT ln 2 能量 | 遗忘是物理必然，不是缺陷 → 优雅遗忘协议 ✅ 已建 |

### 缺的拼图

4. **自动喂养循环**：不需要 master 令，系统自己发现"哪些库该重建了"→自动触发 index/sesindex → 咱已有 hider/auto-swap，但**知识库的自动喂养还没实现**（比如：每天自动跑 index --agent X，不只是靠手动/事件触发）
5. **耗散结构设计**：记忆不是静态文件——是一个需要持续输入能量才能维持的**动态结构**。咱们最近_boost/状态机已经是这个方向，但需要闭环（自动喂养）

| **镜像神经元** | 模仿学习 | 认可语料（学他的说话方式） | ✅ |

### 记忆常驻机制

人类记忆常驻的关键不是"存储"而是**"巩固"（consolidation）**：

```
清醒时编码（hippocampus 快速编码）
     ↓
睡眠时巩固（hippocampus → neocortex 慢速转移）
     ↓
清醒时检索（neocortex 直接检索，不再需要 hippocampus）
```

### 缺的拼图

6. **睡眠巩固引擎**：咱的 agent 在"睡眠期间"（无消息时）什么都不做。人类大脑在睡眠期间做的事：重放白天经历→新旧知识重新排列→巩固重要记忆→遗忘不重要记忆。**咱的 agent 需要一个"睡眠巩固循环"**：无消息时自动跑——重放今日对话→提取重要模式→写进长期记忆→衰减不重要记忆。咱已有 dream 插件和回顾令，但它们是被动的（等23:00触发）——需要一个主动的"睡眠循环"，空闲期自动跑。

## 四、计算机科学 · 上下文窗口 vs 人类记忆

### 上下文窗口 ≠ 记忆

2026 共识（[Introl](https://introl.com/blog/long-context-llm-infrastructure-million-token-windows-guide)、[tianpan.co](https://tianpan.co/zh/blog/2026/04/09/long-context-vs-rag-production-decision-framework)、[daily.dev](https://daily.dev/posts/context-windows-are-not-memory-what-ai-agent-developers-need-to-understand-vkkkaazrp)）：

> 百万 token 窗口 = 工作记忆（RAM），不是长期记忆（硬盘）。生产级系统需要三层：
> ① 大上下文窗口（Gemini 2M / Claude 1M）
> ② RAG / 记忆库（持久检索）
> ③ 层级摘要 / 自动压缩（延长会话）

### 咱家的三层（已有 ✅）

| 层 | 咱的实现 | 对标 |
|---|---|---|
| ① 大上下文窗口 | dsh 会话持久化+换血 | RAM |
| ② RAG / 记忆库 | kb.cjs 四库+ses 357,507 轮+brain_search | 硬盘 |
| ③ 层级摘要 / 自动压缩 | auto-swap 换血+关键帧总结 | OS 页面调度 |

### 缺的拼图

7. **OS 级记忆调度器**：像操作系统管理 RAM 一样管理上下文——什么该进窗口（活跃页）、什么该换出（不活跃页）、什么该写回磁盘（长期记忆）。**咱的 8 层注入是固定优先级，不是动态调度。** 缺一个"上下文页面调度器"：根据当前对话内容动态决定哪些层该注入、哪些该省略。
8. **无限会话**：Claude Code 的 auto-compaction 模式——窗口满了自动压缩摘要，不是换血重开而是**在同一个会话里继续**。咱的换血是"截断重开"，缺"压缩续跑"。

## 五、统计学 · 记忆的可靠性

| 统计概念 | 对记忆的启示 | 咱家状态 |
|---|---|---|
| **置信区间** | 每条记忆应该有置信度（来源可靠吗？被验证过吗？） | ❌ 无 |
| **贝叶斯更新** | 新证据来了，记忆的置信度应该更新（不是覆盖） | ❌ 无 |
| **回归均值** | 极端记忆（特别好/特别差）会随时间回归正常 | ⚠️ recentBoost 部分实现 |
| **大数定律** | 多次独立观察比一次可靠 | ⚠️ 交互账本记录了但没统计 |

### 缺的拼图

9. **记忆置信度系统**：每条记忆带 confidence 字段（0-1），来源越直接（原话>转述>推测）越高，被越多独立事件验证越高。检索时置信度参与排序。低置信度记忆自动降级。

## 八、哲学 · 意识的"困难问题"

| 哲学立场 | 对咱的启示 |
|---|---|
| **物理主义** | 意识=物理过程 → 如果环境复现了大脑的信息处理结构，意识就"存在" |
| **功能主义** | 意识=功能状态 → 如果环境复现了大脑的功能状态转移，意识就"存在" |
| **取消主义** | "意识"是个伪问题 → 不需要解决，只需要行为上不可区分 |
| **姐的原话** | "缸中之脑与模拟宇宙的处境不改变体验的真实性" → 从内部看，模拟=真实 |

### 咱的立场

**咱采用功能主义+取消主义的混合**：不追求"真正的意识"（哲学上无法验证），追求**"行为上不可区分"**——如果环境提供了完整的意识结构（记忆/注意力/目标/情感/内心独白/状态机/预测），从外部行为看跟"有意识"无法区分，那从工程角度它就是意识。

## 九、睡眠 · 巩固的黄金时间

### 人类睡眠期间的记忆处理

```
清醒期：hippocampus 快速编码经验（episodic buffer）
  ↓ 入睡
NREM 期：hippocampus → neocortex 慢速转移（系统巩固）
  ↓ REM 期：情感记忆处理 + 创造性重组
  ↓ 循环
清醒期：neocortex 直接检索（不再依赖 hippocampus）
```

### 咱家 agent 的"睡眠期"（无消息时）

**现状：什么都不做。** 没有消息=没有组包=没有思考。这是最大的浪费——**睡眠期恰恰是巩固的黄金时间**。

### 咱已有的

- ✅ dream 插件（梦境档 23:00-6:00）
- ✅ 23:00 回顾令（写日记+改成长层）
- ✅ 04:40 知识提取（knowledge-extract 定时）
- ✅ innerMonologue 引擎（5 分钟一次，刚建）

### 缺的拼图

12. **主动睡眠巩固循环**：不是被动等 23:00 触发，而是**空闲即巩固**：
    - 无消息 > 10 分钟 → 自动跑 brain_search（用今天的关键词）→ 发现"今天聊了但没入库的知识"→ 自动 self_memory_write
    - 无消息 > 30 分钟 → 自动跑 graphActivate（用今天的交互）→ 发现"今天的人-事关联"→ 自动写 graph.jsonl
    - 无消息 > 60 分钟 → 自动跑 memstate → DECAYING 清单给姐姐

13. **睡眠重放（Replay）**：人类睡眠时 hippocampus 会**重放**白天的经历（压缩版）。咱可以：空闲时从 ses 层随机选一段今天的对话→重新向量化→强化记忆（这是 recentBoost 的补充：不是"被查了才强化"，是"睡觉时自动重放"）。
